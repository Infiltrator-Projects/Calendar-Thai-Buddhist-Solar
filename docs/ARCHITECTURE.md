# Historical Thai Buddhist Solar Calendar — provider architecture

This repository owns its particular historical calendar implementation and release assets. Public ABI, generic mathematics, data conversion and temporal coordinates are consumed through authoritative Common 1.19.80 at commit dc4aac326964ca4400b6e21851d16eea674040c8. Builds link Common's own static archive; copied Common sources and headers are removed. Standalone release source archives and native installers carry an exact Common snapshot for offline installation. Preserved accuracy tests and native package checks are required for each release.
