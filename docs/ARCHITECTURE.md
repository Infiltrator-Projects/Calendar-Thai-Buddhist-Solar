# Historical Thai Buddhist Solar Calendar — provider architecture

This repository owns its particular historical calendar implementation and release assets. Public ABI, generic mathematics, data conversion and temporal coordinates are consumed through authoritative Common 1.19.81 at commit a99ef676b0e43c7e645c81756e3fd38be0a54406. Builds link Common's own static archive; copied Common sources and headers are removed. Standalone release source archives and native installers carry an exact Common snapshot for offline installation. Preserved accuracy tests and native package checks are required for each release.
